# 2026 간사이 여행 일정 PWA

오사카·교토·나라 3박 4일 여행용 모바일 일정 관리 앱입니다.

## 포함 기능
- 4일 일정 탭
- 일정 완료 체크
- 일정 추가/수정/삭제
- 장소별 Google Maps 검색
- 일차별 지출 기록
- 출발 전 체크리스트
- 일정 지연 시 생략 우선순위
- 브라우저 LocalStorage 저장
- JSON 백업/복원
- PWA 설치 및 오프라인 캐시

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 최상위에 업로드합니다.
3. GitHub 저장소 Settings → Pages로 이동합니다.
4. Deploy from a branch를 선택하고 `main` / `/ (root)`를 지정합니다.
5. 생성된 Pages 주소를 갤럭시에서 열고 브라우저 메뉴 → 홈 화면에 추가 또는 앱 설치를 누릅니다.
